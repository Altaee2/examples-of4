محاكي عكس الرقم (C++ Reverse Visualizer)

تتبع حركة المتغيرات داخل حلقة `while` خطوة بخطوة للفهم الكامل

كود الدالة `cal()` في C++

void reverse::cal() {
n1 = no;
r = 0;
while (no > 0) {
d = no % 10; // استخراج المقتطع
r = (r * 10) + d; // إضافة المقتطع للناتج
no /= 10; // حذف الخانة الأخيرة
}
}

شاشة قيم المتغيرات الآنية

الرقم المتبقي (no) 0
الرقم المقتطع (d = no % 10) 0
الناتج المقلوب (r) 0
الرقم الأصلي المحفوظ (n1) 0
